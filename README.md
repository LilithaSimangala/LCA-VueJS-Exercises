# Cooking Masterclass Catalogue (Vue.js)

## 📌 Project Overview
This is a Vue 3 single-page application for Cooking Masterclass. It allows users to browse cooking courses, view chef details, pricing, and skill levels, and save courses to a wishlist.

The project demonstrates component-based development using Vue, props, events, and local data management.

---

## 🚀 Features
- Dynamic course catalogue using Vue components
- Wishlist functionality with live counter
- Sold out course indicator
- Responsive card layout
- Clean and simple UI design

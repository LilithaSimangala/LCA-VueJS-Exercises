# Week 9 Exercise 04 - Fitness Class Scheduler

## 📌 Project Overview
This project is a simple Vue.js application for managing fitness class schedules at FlexZone Fitness.  
It allows users to add, view, and delete scheduled fitness classes such as yoga, pilates, and strength training.

The goal is to demonstrate component-based development, reactivity, and form handling using Vue 3.

---

## 🚀 Features
- Add new fitness classes using a form
- Display a list of scheduled classes
- Delete classes when they are cancelled
- Form validation (no empty fields allowed)
- Dynamic class count using computed properties
- Empty state message when no classes exist

---

## 🛠️ Technologies Used
- Vue 3
- Vite
- JavaScript (ES6)
- HTML5 & CSS3

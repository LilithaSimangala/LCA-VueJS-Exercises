# Property Mini Listings - Homes & Beyond

## 📌 Project Overview
This is a Vue.js single-page application that displays property listings for a fictional real estate startup called Homes & Beyond. Users can browse properties, search by title or location, sort by price, and mark properties as favourites.

The goal of this project is to demonstrate component-based development, props, computed properties, and event handling in Vue 3.

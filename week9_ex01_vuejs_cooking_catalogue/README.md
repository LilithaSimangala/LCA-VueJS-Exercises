# Cooking Masterclass Catalogue

## Brief Project Overview

This project is a Vue 3 single-page application developed for Cooking Masterclass. It allows users to browse a catalogue of cooking courses, view details such as the chef, price, and skill level, and save courses to a wishlist. The application uses reusable Vue components, local data, props, and events to create an interactive catalogue experience.

## Installation and Run Instructions

1. Open a terminal inside the project folder.

2. Install the required dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open the local URL displayed in the terminal (for example, http://localhost:5173) in your web browser to view the application.
